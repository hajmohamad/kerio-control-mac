# Kerio Control macOS Standalone Client

یک لانچر و ابزار کمکی بومی برای اجرای رابط کاربری کلاینت کریو کنترل در نسخه‌های مدرن سیستم‌عامل مک (macOS 13 Ventura، macOS 14 Sonoma، macOS 15 Sequoia و نسخه‌های جدیدتر).

---

## چرا نسخه رسمی در مک‌های جدید باز نمی‌شود؟

1. **حذف پنل‌های تنظیمات قدیمی توسط اپل:** در نسخه‌های مدرن macOS، بخش تنظیمات به SwiftUI بازنویسی شد و پشتیبانی از فایلهای `.prefPane` شخص ثالث به طور کامل حذف گردید.
2. **باگ کرش برنامه:** رابط کاربری قدیمی کریو هنگام بررسی آیتم‌های ورود به سیستم، با یک باگ حافظه ناشی از آزادسازی اشاره‌گر خالی مواجه شده و بلافاصله بسته می‌شد.
3. **عدم اجرای خودکار سرویس پس‌زمینه:** در نسخه‌های جدید مک، دیمن سرویس به مجوز صریح ادمین برای اجرا نیاز دارد.

این پروژه یک نرم‌افزار سبک Cocoa به همراه یک هوک اصلاحی کوچک است که بدون تغییر کدهای اصلی سیستم، پنجره رسمی تنظیمات کریو را مستقیماً در قالب یک پنجره استاندارد مک اجرا می‌کند.

---

## پیش‌نیازها

* نصب اولیه پکیج رسمی Kerio Control VPN Client روی مک (جهت قرارگیری درایور شبکه و سرویس در سیستم).

---

## راهنمای نصب و استفاده

1. از بخش **Releases** فایل `Kerio Control-macOS-Universal.dmg` را دانلود کنید.
2. فایل را باز کرده و آیکون **Kerio Control** را به پوشه **Applications** بکشید.
3. برنامه را اجرا کنید.
4. در صورت مشاهده وضعیت قرمز برای سرویس، دکمه **Start Service** را بزنید و رمز سیستم خود را برای راه‌اندازی سرویس وارد کنید.
5. مشخصات اتصال (سرور، نام کاربری و رمز عبور) را وارد کرده و روی **Connect** کلیک کنید.

---

## نحوه بیلد از سورس‌کد (برای توسعه‌دهندگان)

نیازمندی: ابزار خط فرمان Xcode (`xcode-select --install`).

```bash
# بیلد برنامه به صورت Universal (سازگار با Apple Silicon و Intel)
./build.sh

# ساخت پکیج‌های DMG و ZIP جهت انتشار
./build.sh release
```

فایل‌های خروجی در پوشه `dist` ایجاد خواهند شد.
